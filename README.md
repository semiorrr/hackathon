**Feature Description for eSeal Alert App:**

The **eSeal Alert** app is a real-time container monitoring system designed to track the status and location of sealed containers. Here are its key features:

1. **User Authentication & Personalized Dashboard**  
   - Users (e.g., "test123") are greeted with a personalized dashboard upon login.

2. **Real-Time Container Status Monitoring**  
   - Displays the current status of containers (e.g., "Sealed" or "Tempered") in a tabular format.  
   - Highlights anomalies (e.g., "X Tempered" for CNT-005) to alert users of potential breaches.

3. **Detailed Container Tracking**  
   - Tracks each container’s unique ID (e.g., CNT-001 to CNT-005).  
   - Shows the last updated timestamp (e.g., "2025-04-30 05:32:06") for transparency.  
   - Provides real-time location updates (e.g., "Cebu Port," "Taglaiaran Pier").

4. **Alert System**  
   - Automatically flags containers with "Tempered" status for immediate attention.  
   - Timestamps all changes to help users investigate incidents.

5. **User-Friendly Interface**  
   - Clean, organized table layout for easy readability.  
   - Clearly distinguishes normal ("Sealed") and critical ("X Tempered") statuses.

**Purpose:**  
The app ensures secure logistics by enabling users to monitor container integrity in real time, detect tampering, and respond swiftly to unauthorized access. Ideal for logistics companies, port authorities, and supply chain managers.
